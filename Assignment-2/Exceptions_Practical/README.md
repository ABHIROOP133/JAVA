# Exceptions Practical Assignment

This directory contains the practical assignment code for **Section 3: Errors and Exceptions**.

### 7. Exception Handling (try-catch vs try-catch-finally)
- **Location:** `Question07_ExceptionHandling/ExceptionHandlingDemo.java`
- **Description:** This program demonstrates how a `try-catch` block handles an `ArithmeticException` (division by zero). It also demonstrates a `try-catch-finally` block to show that the `finally` block always executes, regardless of whether an exception occurs.

### 8. Custom Exception (`InvalidAgeException`)
- **Location:** `Question08_CustomException/`
  - `InvalidAgeException.java`: The custom exception class that extends `Exception`.
  - `CustomExceptionDemo.java`: The main class that throws and handles the custom exception if the user's age is less than 18.
- **Description:** This program takes a user's age as input and validates it using a custom exception.
